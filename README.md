## 👋 About This Repository

Welcome to my personal journey of mastering the **C Programming Language**. As a BCA 1st Semester student at **Prayagraj University (PRSU)**, I believe that strong foundations are built through consistent practice and structured problem-solving.

This repository serves as a digital notebook where I document every concept I learn—from basic variables to complex conditional logic. Each file is designed to be self-contained, well-commented, and ready to compile.

> *"Code is like humor. When you have to explain it, it’s bad."*  
> — But here, I explain everything so YOU don't have to guess! 😄
