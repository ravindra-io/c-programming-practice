## How to Run

You need GCC installed. Then open terminal inside the folder and run:

```bash
# step 1 — go into the folder
cd 01_Variables_and_Data_Types

# step 2 — compile
gcc q01_print_int.c -o q01

# step 3 — run on Windows
q01.exe

# step 3 — run on Linux / Mac
./q01
```

## FAQ

**Who is this for?**
Anyone who is just starting out with C. These programs are small and focused so they are easy to follow even if you are in your first week of learning.

**Why are files named with numbers?**
So they stay in order inside the folder. It is easier to find q08 than to remember what the 8th program was called.

**Can I use or copy these programs?**
Yes. Use them however you want — for practice, reference, or understanding how a concept works.

**How do I know what each program does without opening it?**
Every file has a comment at the top with the description and expected output. You can read that before compiling.
