# C Programming Practice Journal

Each program covers one concept and has a comment explaining what it does.

**Author:** Ravindra Yadav
**Course:** BCA 1st Semester

| Range | Topic | Concepts |
|-------|-------|----------|

## FAQ

**Who is this for?**
Anyone starting out with C. Especially BCA or B.Tech 1st year students.

**Why are files named with numbers?**
So they stay in order and are easy to find.

**Can I use these programs?**
Yes, use them however you want.

**Where is the description for each program?**
At the top of every file in a comment.
