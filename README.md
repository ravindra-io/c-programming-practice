## 💻 EXECUTION ENGINE

To run these programs, ensure your environment is equipped with the **GCC Compiler**.

### ️ Setup Instructions

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/ravindra-io/c-programming-practice.git
    cd c-programming-practice
    ```

2.  **Navigate to a Module:**
    ```bash
    cd 01_Variables_and_Data_Types
    ```

3.  **Compile & Execute:**

    **For Linux / macOS Users:**
    ```bash
    gcc q01_print_int.c -o execution_binary
    ./execution_binary
    ```

    **For Windows Users:**
    ```cmd
    gcc q01_print_int.c -o execution_binary.exe
    execution_binary.exe
    ```
